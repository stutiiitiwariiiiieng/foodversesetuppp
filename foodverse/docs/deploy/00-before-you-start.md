# Step 0: Before you start

Time needed: about 5 minutes.

## Accounts (all free)
1. GitHub: https://github.com/signup
2. Render: https://render.com (sign up with GitHub in Step 2)
3. Vercel: https://vercel.com (sign up with GitHub in Step 3)

## Things to get
1. **Anthropic API key**
   - Go to https://console.anthropic.com, sign in, open **API Keys**, click **Create Key**.
   - Copy it and keep it somewhere private. You only see it once.
   - Your account needs some credit for the AI calls to work.
2. **Git**
   - Download from https://git-scm.com and install with the default options.
   - Check it worked: open a terminal and run `git --version`.
3. **The project**
   - Unzip `foodverse.zip`. You get a folder called `foodverse`.

## Checklist
- [ ] GitHub account created
- [ ] API key copied
- [ ] `git --version` prints a version
- [ ] Project unzipped
